## Status language

Documentation uses the following statuses:

- **Implemented:** code exists and has been executed.
- **Validated:** implemented behavior passed the stated experiment or test.
- **Specified:** design and acceptance criteria exist; code does not yet exist.
- **Proposed:** a candidate direction requiring review.
- **Deferred:** deliberately outside the competition scope.

No document may describe a specified component as implemented.
